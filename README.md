# lumina — public legal pages

Published at **https://woongsu-kim.github.io/lumina/**

This repo holds **only** the legal documents shown to App Store reviewers and users.
The app source is not published here.

Source of truth: the `PRIVACY.md` / `TERMS.md` / `ATTRIBUTION.md` files in the (private)
Lumina app repository. Files here are copies with lowercase names so the URLs read
`/privacy.html`, `/terms.html`, `/attribution.html`.

Update procedure: edit the app repo, copy the three files here (lowercased), commit — the
Pages URL stays the same.
